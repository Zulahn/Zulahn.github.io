# Portfolio Website - Åsmund Dæhlen

Personal portfolio showcasing design research, academic work, and creative projects.

Live site: [dæhlen.com](https://dæhlen.com)

## Structure
- `/academic/` - Case studies & research
- `/tools/` - Interactive utilities
- `/lab/` - Experiments & prototypes
- `/creative/` - Music & art (coming soon)

## Development
This repository is deployed via GitHub Pages. The main development repository is maintained separately at `portfolio-website/`.

## Deployment
Changes are pushed directly to the `main` branch, which automatically deploys via GitHub Pages.
